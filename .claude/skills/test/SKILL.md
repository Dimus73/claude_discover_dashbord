Запусти тесты сервера и клиента. Собери результаты и выведи сводный отчёт.

## Шаг 1 — Тесты сервера

```bash
cd /Users/dmitryprigozhin/repos/claude_discover_dashbord/server && npm test -- --coverage --forceExit 2>&1
```

Если `jest` не установлен (команда не найдена или нет `"test"` в package.json) — сообщи:
> Тесты сервера не настроены. Запусти `/test-writer` для создания первых тестов.

Запомни:
- Сколько тестов прошло (`X passed`)
- Сколько упало (`X failed`)
- Итоговый % покрытия (строки из таблицы coverage)
- Текст ошибок если были падения

## Шаг 2 — Тесты клиента

```bash
cd /Users/dmitryprigozhin/repos/claude_discover_dashbord/client && CI=true npm test -- --coverage --watchAll=false 2>&1
```

Запомни:
- Сколько тестов прошло
- Сколько упало
- Итоговый % покрытия
- Текст ошибок если были падения

## Шаг 3 — Итоговый отчёт

Выведи таблицу:

| Часть | Тестов | Прошло | Упало | Покрытие |
|---|---|---|---|---|
| Сервер | N | N | N | XX% |
| Клиент | N | N | N | XX% |
| **Итого** | N | N | N | — |

Затем:
- Если все тесты прошли: **Все тесты зелёные.**
- Если есть падения: перечисли какие тесты упали и краткую причину из вывода.
- Если тесты отсутствуют в какой-то части: укажи это явно и предложи запустить `test-writer` агента.
